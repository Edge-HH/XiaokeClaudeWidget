# 设计简报

## 用途
在 Claude Desktop 窗口里显示原版小克宠物和账号额度。

## 用户
Windows 桌面用户，希望通过右键配置额度来源，不需要理解开发工具。

## 原则
- 原版造型、布局、台词、交互优先于重新设计。
- 订阅百分比与账户金额始终使用不同口径。
- 缺少数据时明确显示不可用，不编造数值。
- 其他应用在前台时宠物隐藏，空白区域允许点击穿透。

## 成功标准
用户可以获取原版素材、保存查询来源、查看额度，并继续正常操作宿主。

## 范围外
- 修改宿主程序或读取聊天内容。
- 自动更新、自动发布、默认开机自启。
- 开发测试期间运行 Claude 或查询真实 Claude 账号。

# 来源与许可

本项目适配 [aklnaaw/dsh-xiaoke-widget](https://github.com/aklnaaw/dsh-xiaoke-widget)，固定版本 `4822bac4acc742ad91787495b9dd9ec32a38b1b7`。
该项目二创自 [MeteorNOX/DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)。

原版代码适用 MIT；原始版权与许可全文保留在源码 `vendor/upstream/LICENSE`，也完整附于本文下方。本文随公开交付包提供。
桌面适配代码采用根目录 LICENSE。

原版 `assets/**`（角色图片、动图、音效）不属于 MIT。公开源码及安装包不内置这些素材；首次使用时由用户选择从固定上游获取，或导入同版本的素材目录。
素材保持原字节，不声明原创、不授予再许可。获取方式不构成新的素材授权，须遵守原作者说明。

详细说明见 [原版 PROVENANCE](https://github.com/aklnaaw/dsh-xiaoke-widget/blob/4822bac4acc742ad91787495b9dd9ec32a38b1b7/PROVENANCE.md) 和 [继承素材说明](https://github.com/aklnaaw/dsh-xiaoke-widget/blob/4822bac4acc742ad91787495b9dd9ec32a38b1b7/upstream/PROVENANCE.upstream.md)。

这是独立的第三方工具，与 Anthropic、Claude Desktop、DeepSeek、New API 无官方关联。

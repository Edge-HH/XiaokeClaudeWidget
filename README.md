# 小克额度宠物

独立 Windows 宠物程序，复用 [原版小克](https://github.com/aklnaaw/dsh-xiaoke-widget) 的角色与交互，贴在 Claude Desktop 窗口内侧。不会修改或注入 Claude Desktop，也不会读取对话。

支持 Claude 账号五小时／周额度、DeepSeek 账户余额、New API 令牌额度和账户余额。Claude 额度由整个账号共享，不是 Desktop 单独用量。

## 安装与首次使用

Windows 10/11 x64，选择 `XiaokeWidget-0.1.5-setup.exe` 安装版或 `XiaokeWidget-0.1.5-portable.exe` 便携版。安装版默认按当前用户安装，可选择目录；两者自带运行组件，不需要安装 Node、.NET 或 DSH。

0.1.5 针对“关闭设置才可见、无法点击拖动、打开普通菜单消失”，改为可见期间稳定保持覆盖层级，并让设置位于宠物之上。普通菜单不再激活窗口，仅输入编辑允许键盘焦点；穿透区采用光标轮询，拖动使用指针捕获，不再混入无按键的转发移动。宿主前台与小克前台分别识别，空前台的短暂激活过渡不立即隐藏。保留之前的首次就绪、菜单位置恢复与错误弹窗修复。本版本按用户要求只编译打包，运行效果由用户自行验证。

升级前从托盘退出旧版小克；原有配置及素材保存在用户目录，安装新版时会继续使用。宿主需要处于前台；素材已就绪时，启动不应再依赖打开、关闭设置来唤醒宠物。宿主弹窗出现时保持贴附主窗口；窗口辅助组件或宠物页面意外退出后会自动尝试恢复，连续失败最多重试三次，状态区会保留故障提示。

1. 运行小克，打开“查询来源与素材”。程序本身不会启动 Claude。
2. 点击“获取原版素材”，或自行下载[固定版本原版插件](https://github.com/aklnaaw/dsh-xiaoke-widget/archive/4822bac4acc742ad91787495b9dd9ec32a38b1b7.zip)，解压后导入 `assets` 目录。素材按固定字节校验，不随本项目公开包分发。
3. 填写来源配置，点击“保存并使用”。可以保存多个来源，只查询当前启用的一项。
4. 你自行打开 Claude Desktop 后，小克自动贴附；右键小克打开原版菜单和“查询来源”。宿主最小化、关闭或其他应用在前台时隐藏宠物。无宿主时仍可从托盘打开配置。

素材的图片、动图、音效不属于代码 MIT 许可，详见 [NOTICE](NOTICE.md)。软件默认不开机自启，没有自动更新。

## 配置查询来源

### Claude

使用与 Desktop 相同的账号。你可以在浏览器自行登录 Claude，打开开发者工具的“应用／Application → Cookies → claude.ai”，复制 `sessionKey` 的**值**。不要复制整个 Cookie，不要把会话值发送给别人。

将该值粘贴到小克，点击“读取组织列表”，选择对应组织，再保存。小克不读取 Desktop 的登录文件，不自动打开登录程序，也不能核验 Desktop 当前使用哪个账号。

修改已有来源的查询类型或 New API 站点时，需要重新填写相应凭据；留空只保留同一类型、同一站点的已存密钥。保存失败时保留原配置和凭据，不将旧密钥用于新来源。

查询使用非公开的 `claude.ai/api/organizations/{id}/usage` 会话接口。接口可能变化或因会话到期、站点访问限制返回 401/403；遇到这些情况请重新配置或切换来源。不会通过发送聊天消息测试连接。

### DeepSeek

填写 DeepSeek API Key，可以粘贴单个密钥或带 `Bearer` 前缀的值。程序仅查询 `/user/balance`，保留原版人民币钱包优先规则并显示接口返回的币种。原版余额观测记账、充值校正和峰谷显示继续保留；今日消费是本地观测口径，不是单独的 Desktop 消费。观测区间按原版北京时间划分，价格展示沿用固定原版，不保证服务商之后的价格变化已同步。

### New API

- 令牌额度：填写站点根地址与 API Key，查询 `/api/usage/token/`。
- 账户余额：填写站点根地址和个人设置中的账户访问令牌，查询 `/api/user/self`。新版 PAT 可不填用户 ID，旧站点需要时再填写数字 ID，见 [New API 鉴权说明](https://github.com/QuantumNous/new-api/blob/main/docs/authentication.md)。

API Key／账户访问令牌均支持可选 `Bearer` 前缀；站点部署在子路径时可以保留该子路径，不要填写模型请求的 `/v1` 地址。

单个令牌的额度与整个账户余额是不同口径；“无限额度”只表示令牌限制。站点参数来自 `/api/status`；没有可靠换算参数时显示原始“额度”。已知站点参数时可以展开手动换算。累计已用不标成“今日已用”。

## 原版交互与限制

保留缩放、拖动、吸附、翻转、点击台词、泡泡点击队列、样式、音效试听、自定义角色／泡泡图片／音频编辑和资源管理。来源切换只调整额度内容；订阅百分比不进入金额记账。

额度卡保留原版底色和文字颜色，打开的额度泡泡会跟随查询状态更新；失败保留旧余额并显示原因。切换查询来源时收起旧泡泡，避免把上一个账号的余额留在新来源下。

长来源标题省略显示，鼠标提示可查看全名。宠物靠近顶部或宿主变小时，主菜单会保持在客户区内并可滚动。原版遗留的其他厂商额度模块会提示到“查询来源”配置，不显示无法验证的旧额度。

每轮消耗、生成等待、任务结束事件和聊天页面布局调整需要宿主聊天事件，贴附模式无法取得，相关设置标为不可用。不会把额度差值冒充每轮消耗。原版“新增模型”入口转向桌面“查询来源”；其他厂商外部探活与本机会话扫描已停用。

默认每 60 秒刷新；宠物和设置均隐藏时暂停轮询，重新显示可恢复查询。请求超时为 10 秒，限流遵守重试时间；网络故障可手动立即重试，失败保留旧数据并标明。切换来源保留该来源的缓存，修改配置或凭据后重新查询。重置时间到达时重新查询，不直接清零用量。

## 本地数据与排查

设置和素材保存在当前用户的应用数据目录（通常 `%APPDATA%\xiaoke-claude-widget`），演示模式使用独立的 `%APPDATA%\XiaokeWidget-demo`。密钥由 Electron safeStorage／Windows DPAPI 加密，绑定当前 Windows 账户；复制到另一台机器可能需要重新配置。

- 看不到宠物：托盘打开设置，先看“窗口贴附状态”和“运行版本”，再确认素材已就绪。状态区会区分辅助组件失败、宿主未识别、页面加载／桥接失败和宿主未在前台，并显示覆盖层和输入编辑状态。窗口处于显示状态、收到位置回执不等于肉眼可见或鼠标可用；这些仍需在宿主中确认。显示状态读取不查询账号。
- 新版未生效：程序只允许一个实例；先从旧版托盘选择“退出小克”，再运行新版。设置里显示的是实际运行版本。
- 登录失效／查询被拒：核对来源凭据和组织，不要反复刷新绕过限流。
- 原始额度没有币种：站点没有公开足够的换算参数，程序不会猜测美元或人民币。
- 配置损坏：程序暂停启动保存，保留原文件。先备份用户数据，再检查 `preferences.json`；无需改 Claude Desktop。
- 通过退出托盘关闭程序；卸载安装版不会主动删除保存的用户数据。

## 开发与验收

```powershell
npm ci
npm run native:build
npm run dev
```

未打包的入口默认使用本项目模拟宿主和模拟额度。`npm start` 也处于模拟模式；真实窗口跟随和真实查询仅用于正常启动的打包成品。打包成品也可以附加 `--demo` 运行模拟模式。

```powershell
npm run upstream:check
npm run typecheck
npm test
npm run test:e2e
npm run test:scaling
npm run package
npm run test:package
```

桌面验收默认使用 DeepSeek 假余额，DeepSeek／New API 请求全部模拟或使用本机 HTTP 服务。演示／测试模式拒绝 Claude 查询与组织读取，页面禁止 HTTP(S) 外联；Claude 解析与订阅测试明确跳过。测试禁止启动或连接 Claude Desktop、Claude Code 或其他 Claude 工具，发现相关进程立即终止。首次取得测试素材需要访问 GitHub，之后使用忽略提交的 `.asset-cache`；截图与结果在 `.test-artifacts`，均不进入公开包。

详细维护约定见 [开发说明](docs/development.md)，测试范围见 [验收记录](docs/validation.md)。**真实 Claude Desktop 的兼容性和账号查询未做真实环境验证。**

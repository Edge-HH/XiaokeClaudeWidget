## 0.1.1 错误弹窗修复

定位到本项目残留测试进程的主进程异常：`TypeError: Object has been destroyed`。宠物窗口被销毁后，32 毫秒定时器先读取 `isVisible()`，再检查 `isDestroyed()`，因此关闭异常对话框后下一次回调再次报错。模拟宿主回归测试在修复前的 180 毫秒内捕获 5 次相同异常；修复后先检查存活状态，并在窗口销毁与退出时清理定时器、释放窗口引用。

回归入口：`npm run test:lifecycle`；成品回归入口：`node tests/window-lifecycle.mjs --package`。检查宠物窗口单独销毁、后续宿主更新、全部窗口销毁及应用退出，不启动真实 Claude 工具。
